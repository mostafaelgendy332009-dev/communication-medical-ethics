إضافة الشات دون استبدال ملفات الموقع

1) ارفع الملفات الأربعة التالية إلى جذر مستودع GitHub (نفس المكان الذي يوجد فيه index.html):
   chat.html
   chat-addon.css
   chat-addon.js
   README-ADDON.txt

2) بعد الرفع افتح رابط الشات:
   https://mostafaelgendy332009-dev.github.io/communication-medical-ethics/chat.html

3) افتح المنصة الرئيسية وسجّل الدخول من نفس المتصفح أولًا. صفحة الشات تستخدم جلسة Firebase نفسها وتقرأ اسم العضو من عضويته الموجودة.

مهم: هذه الملفات لا تستبدل ملفات الموقع الحالية. يلزم أيضًا السماح لمجموعة messages في Firestore Rules قبل أن ينجح إرسال/قراءة الرسائل. أضف السطر 'messages' إلى قائمة المجموعات المسموح بها في القاعدة العامة الحالية، ثم Publish من Firebase Console. لا ترفع ملف القواعد إلى GitHub وتتوقع أن يتطبق تلقائيًا.

الخصوصية: الرسائل متاحة لأعضاء الجروب المسجلين، وكل عضو يستطيع حذف رسائله هو فقط إذا كانت قواعد Firestore تسمح بذلك.
