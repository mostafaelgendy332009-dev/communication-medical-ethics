# TeamSpace — Communication & Medical Ethics

منصة ويب مشتركة لإدارة مهام وتصويتات واجتماعات ومصادر فريق المادة.

## ما الذي يعمل في النسخة الحالية؟
- دخول باسم العضو وكود الجروب.
- تحديث مباشر للبيانات بين الأعضاء عبر Cloud Firestore.
- لوحة إحصائيات، وإضافة/تعديل/حذف المهام.
- تصويت علني أو سري من حيث إخفاء أسماء المصوتين (النتائج ظاهرة).
- قائمة أعضاء، واجتماعات، ومصادر وروابط.
- سجل نشاط أساسي.

## مهم قبل الاستخدام
هذه حزمة مصدر جاهزة للإعداد وليست رابطًا منشورًا بالفعل. يلزم إنشاء مشروع Firebase وربطه ثم نشر الملفات على استضافة HTTPS.

### 1) إنشاء Firebase
1. افتح https://console.firebase.google.com وأنشئ مشروعًا.
2. أضف Web App وانسخ إعدادات Firebase إلى `firebase-config.js`.
3. من Authentication > Sign-in method فعّل **Anonymous**.
4. من Firestore Database أنشئ قاعدة بيانات.
5. من تبويب Rules الصق محتوى `firestore.rules` وانشره.

### 2) إعداد كود الجروب
في Firestore أنشئ المستندات التالية يدويًا:
- Collection: `groups`
- Document ID: `communication-medical-ethics`
- Subcollection: `joinCodes`
- Document ID: كود الانضمام الذي ستشاركه مع الفريق (يفضل كودًا طويلًا وغير متوقع)
- Fields: `active` من النوع Boolean وقيمته `true`

مثال هيكلي:
`groups / communication-medical-ethics / joinCodes / TEAM-7K9P-4Q2M`
وفي المستند حقل `active: true`.

لا تنشئ بيانات الأعضاء أو المهام يدويًا؛ التطبيق ينشئها عند الاستخدام.

### 3) تشغيل محلي للاختبار
لأن التطبيق يستخدم JavaScript modules، شغّله عبر خادم محلي وليس بفتح `index.html` مباشرة.
مثال باستخدام Python:
`python -m http.server 8000`
ثم افتح `http://localhost:8000`.

### 4) النشر
يمكن نشر المجلد على Firebase Hosting:
1. ثبّت Firebase CLI على جهاز كمبيوتر.
2. نفّذ `firebase login`.
3. من مجلد المشروع نفّذ `firebase init hosting` واختر مجلد النشر الحالي.
4. نفّذ `firebase deploy`.

يمكن أيضًا رفعه على أي استضافة Static تدعم HTTPS.

## ملاحظات أمان وحدود النسخة الأولية
- الدخول مجهول (Anonymous Auth)؛ الاسم الذي يكتبه العضو ليس إثباتًا لهويته. جلسة العضو مرتبطة بالمتصفح والجهاز، وقد يحتاج العضو لإعادة الانضمام إذا فقد بيانات المتصفح.
- كود الجروب وسيلة انضمام للفريق وليس نظام تحقق قويًا من الهوية. شاركوه داخل الجروب فقط، واستخدموا كودًا طويلًا.
- خيار «سري» يخفي أسماء المصوتين في واجهة العرض فقط؛ لا تعتبره اقتراعًا حساسًا أو مضمون السرية على مستوى التدقيق الإداري. لا تستخدموه لقرارات تتطلب سرية رسمية.
- النسخة الحالية مخصصة لجروب واحد ثابت. يمكن تطويرها لاحقًا لدعم عدة جروبات، صلاحيات متقدمة، رفع ملفات فعلي، إشعارات، وتسجيل دخول قابل للاسترداد.
- أي عضو مسجل يستطيع في النسخة الأولية تعديل وحذف البيانات. لا توجد صلاحيات قائد افتراضية.

## هيكل الملفات
- `index.html` — واجهة المنصة.
- `style.css` — التصميم المتجاوب.
- `app.js` — وظائف Firebase والتفاعل.
- `firebase-config.js` — إعدادات مشروعك.
- `firestore.rules` — قواعد الوصول.
